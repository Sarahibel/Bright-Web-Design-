Bright Web Design is a fictional small web design company. The company helps businesses create simple, attractive, and easy-to-use websites. It focuses on creativity, responsive design, and accessibility to make websites that everyone can use.

1. What accessibility challenges did you face, and how did you address them?

The challenge I faced was making sure the website was easy for everyone to use. I added labels to the contact form, and colors that make the text easier to read. I also added keyboard focus so users can see which link or button they are selecting.

2. How did you ensure that your design was responsive and accessible to all users?

I used CSS Flexbox and Grid to organize the website. I also added media queries for 1024px and 600px so the website can adjust to different screen sizes, including tablets and mobile phones. I made the navigation and service cards adjust on smaller screens.

3. What tools or resources did you find most helpful during this project?

I used Visual Studio Code to write my HTML and CSS. I also used Google searches, W3Schools, and YouTube videos to learn and understand how to build the website. These resources helped me when I had questions or needed examples. I also practiced by making changes to my code and checking the results in my browser.
